# Как пользоваться StackEdit

Интерфейс приложения — на английском (это апстрим, перевода нет). Здесь — как им пользоваться на
самом деле: что где лежит, что сохраняется само, что требует отдельных ключей и что не работает
вовсе.

## Что это

StackEdit — редактор Markdown, который живёт целиком в браузере. Ни аккаунта, ни сервера для работы
не нужно: файлы лежат в IndexedDB этого браузера, текст перерисовывается на лету, приложение
устанавливается как обычное (PWA) и работает офлайн после первой загрузки.

Готовый адрес — <https://dnikulshin.ru/stackedit/>. Собрать и раздать локально —
[quickstart.md](quickstart.md) и [build.md](build.md).

## Интерфейс

| Область | Что там |
| --- | --- |
| **Навигационная панель** (сверху) | имя текущего файла (клик — переименовать), «Synchronize now», «Publish now», кнопки форматирования (жирный, курсив, заголовок, списки, цитата, код, таблица, ссылка, картинка), Undo/Redo |
| **Explorer** (слева) | дерево файлов и папок: создать файл, создать папку, переименовать, удалить; «Toggle explorer» прячет панель |
| **Редактор** (центр) | разбит на секции: текст и его предпросмотр рядом, прокрутка синхронизируется |
| **Боковая панель** (справа) | предпросмотр, оглавление (TOC), обсуждения; кнопки «Toggle side preview», «Reader mode», «Toggle focus mode», «Toggle scroll sync», «Toggle status bar» |
| **Статус-бар** (снизу) | для Markdown: байты, слова, строки, позиция `Ln 1, Col 0`; для результата: символы HTML, слова, абзацы |
| **Меню** (три вертикальные полоски) | Workspaces, Synchronize, Publish, History, File properties, Table of contents, Markdown cheat sheet, Import/export, Print, Badges, Accounts, Templates, Settings, Workspace backups, Reset application, About |

## Файлы и папки

- Новый файл/папка — кнопками в Explorer; переименование — по клику на имя файла в навигационной
  панели или кнопкой в Explorer.
- Удаление отправляет файл в `Trash`; оттуда он удаляется окончательно **через 7 дней** (срок задан в
  коде — `constants.cleanTrashAfter`).
- Пути в рабочем пространстве уникальны: при совпадении имён приложение предложит вариант
  (`file.1`, `file.2`), молча ничего не перезаписывает.
- Файл можно перетаскивать между папками в дереве.

## Как сохраняется текст

Сохранять вручную не нужно: изменения из стора пишутся в IndexedDB раз в секунду (локальная база
`stackedit-db`, стор `objects`). Настройки — в `localStorage`.

Из этого следует главное ограничение: **данные привязаны к браузеру и к адресу сайта**. Другое
устройство, другой браузер, другой профиль или другой адрес — это другая пустая база. Переносить:

1. **Workspace backups → Export all workspaces backup** — один JSON со всеми локальными базами.
   **Import workspace backup** восстанавливает выбранное рабочее пространство в текущее: файлы, папки,
   содержимое, **позицию курсора и скролл**. Id файлов, история синхронизации и sync-локации не
   переносятся.
2. **Export workspace backup** / **Import workspace backup** — то же для одного рабочего пространства
   в «плоском» формате `id → item`.
3. Экспорт отдельного файла на диск (Markdown или HTML) — меню **Import/export**.

Браузер вправе удалить локальные данные, если место на диске кончилось. **Settings → Storage**:
показывает, защищено ли хранилище, сколько занято из доступного и даёт запросить постоянное хранение
(`persist()`) и выгрузить бэкап. Chrome и Safari решают сами, Firefox показывает попап — поэтому там
запрос не делается автоматически.

## Markdown и что рендерится

Обычный Markdown плюс расширения: таблицы, списки задач, сноски, SmartyPants (типографика),
`$…$` и `$$…$$` — формулы (KaTeX), ` ```mermaid ` — диаграммы, ` ```abc ` — нотные записи. Подсветка
кода — Prism. При желании расширения отключаются в **File properties** для конкретного файла.

Шорткаты по умолчанию (их можно переопределить в **Settings → Custom settings**):

| Действие | Шорткат |
| --- | --- |
| Синхронизировать | `Ctrl/Cmd + S` |
| Найти / заменить | `Ctrl/Cmd + F` / `Ctrl/Cmd + Alt + F` |
| Жирный / курсив / зачёркнутый | `Ctrl/Cmd + Shift + B` / `I` / `S` |
| Заголовок / цитата / код | `Ctrl/Cmd + Shift + H` / `Q` / `K` |
| Списки: маркированный / нумерованный / чек-лист | `Ctrl/Cmd + Shift + U` / `O` / `C` |
| Таблица / ссылка / картинка | `Ctrl/Cmd + Shift + T` / `L` / `G` |
| Горизонтальная линия | `Ctrl/Cmd + Shift + R` |

## Экспорт

- **Markdown** — как есть, в файл.
- **HTML** — через шаблоны Handlebars (меню **Templates**, 5 шаблонов по умолчанию); шаблон
  определяет, во что превратится документ.
- **PDF и Pandoc (docx, odt, epub…)** — ❌ **не работает** в самостоятельной сборке: обработчик на
  сервере требует платного бэкенда stackedit.io (проверка спонсорства через AWS S3). Это ограничение
  апстрима, не сборки.
- **Print** — печать браузером, со своими стилями.

## Публикация и синхронизация

Провайдеры: GitHub, GitLab, Gist, Google Drive, Dropbox, Blogger, WordPress, Zendesk, CouchDB.
Два разных механизма:

- **Синхронизация файла** — файл в рабочем пространстве связан с файлом у провайдера; при изменениях
  выполняется merge. Отсюда же берётся **History**: список ревизий хранится у провайдера, поэтому
  история доступна только для синхронизированного файла (или после входа через Google для
  синхронизации рабочего пространства).
- **Публикация** — одноразовая (и повторяемая) выгрузка в блог/страницу.

Чтобы это заработало в самостоятельной сборке, нужны **свои OAuth-ключи**: см.
[self-host.md](self-host.md). Без них работает всё остальное — редактор, файлы, экспорт, бэкап.

## Настройки

**Settings → Custom settings** — YAML с переопределениями (пустой файл = значения по умолчанию):

| Ключ | Что делает |
| --- | --- |
| `colorTheme` | `light` / `dark` |
| `fontSizeFactor`, `maxWidthFactor` | размер шрифта и ширина колонки в редакторе и предпросмотре |
| `autoSyncEvery` | период автосинхронизации, мс, минимум 60000 (по умолчанию 90000) |
| `editor.listAutoNumber` | автоматическая нумерация списков |
| `editor.inlineImages` | показывать картинки прямо в редакторе |
| `editor.monospacedFontOnly` | только моноширинный шрифт |
| `shortcuts` | переназначение шорткатов |

Третья вкладка — **Storage** (см. выше). Есть ещё **Default settings** — полный список с
комментариями, оттуда удобно копировать ключи.

## Рабочие пространства

**Workspaces** — их может быть несколько (например, «Main», «Работа», «Личное»), у каждого своя база
`stackedit-db-<id>` в том же браузере. Переключение — в меню **1 Workspaces**. Бэкап всех сразу —
**Workspace backups → Export all workspaces backup**.

## Офлайн и установка как приложение

- Открыли адрес один раз — дальше работает офлайн (Service Worker держит файлы в кэше).
- Android/Chrome: меню → «Установить приложение». iOS/Safari: «Поделиться» → «На экран „Домой“».
- По `file://` приложение не запускается: браузер не даёт ни манифест, ни Service Worker. Нужен
  `http://localhost` или `https://…` — см. [pc.md](pc.md).

## Чего здесь нет

- **Магазина приложений**: отдельного приложения в Google Play у StackEdit нет и не было; установка —
  только как PWA из браузера.
- **Облака по умолчанию**: без своих OAuth-ключей ни синхронизации, ни публикации, ни History.
- **Серверного экспорта PDF/Pandoc** (см. выше).
- **Мультиустройства «из коробки»**: файлы локальны, перенос — бэкапом или через Git-провайдера.
